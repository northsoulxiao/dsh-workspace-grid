# dsh-workspace-grid

一个 DeepSeek Harness 插件：把侧栏的「工作区」列表排成三列瓦片。
开关就是工作区**视图选项**菜单里的一项，和「分组方式」并排，不新增任何图标或按钮。

## 效果

- **关闭（默认）**：和原版完全一样，一列。
- **开启「九宫格（3 列）」**：没有会话的工作区排成 3 列瓦片（文件夹图标在上、名称居中最多 3 行）；
  有会话、或「按工作区树」下带子工作区的工作区仍占满整行，会话列表宽度不变，照旧可读。
- **点开的工作区会高亮**：展开（`aria-expanded="true"`）的文件夹是浅蓝底 + 强调色描边 + 强调色图标/名称，
  一眼能分清「点开了」和「没点开」；收起即恢复。
- **选中的会话也是强调色**：当前打开的会话行使用同一套强调色，工作区 → 会话 → 对话连成一条视觉线索。
- **只改排布**：点击、拖拽排序、右键菜单、悬停卡片（完整名称 + 路径）、新建会话全部沿用官方元素。
- **左侧栏启动时开到最大宽度 420px**：布局本身不持久化侧栏宽度，每次启动都会回到 280px；
  本插件在启动时通过框架自己的拖拽手柄把它拉到契约上限。之后仍然可以正常拖窄 —— 每次加载只设一次。
- 开关状态存在浏览器 localStorage（`dsh.workspaceGrid.enabled`），重启后保持。
- 配色不写死：瓦片底色与高亮色跟随浅色/深色主题（`data-ds-dark-theme`）。

## 安装

把这个目录作为 bundle 安装：

```
插件 → 添加插件 → 本目录的绝对路径
```

或在会话里让 agent 用 `plugin_manager` 的 `install_bundle`，`target` 填本目录。
bundle 的补丁会插入 `workspace-grid` 这一行，因此它会在**插件**列表里带着自己的名称、说明和图标出现。

## 关闭

- 只关视图：在「视图选项」菜单里再点一次「九宫格（3 列）」，勾消失即恢复一列。
- 插件层面：在**插件**里停用（或移除）本 bundle。不会改动任何工作区文件。

## 已知限制

- 插件靠官方 CSS Module 的类名后缀和几个 `aria` 属性定位元素。DSH 升级若改名，规则会失效并退回一列，不会破坏原布局。
- 菜单项的键盘上下切换只覆盖官方菜单项，注入的这一项用鼠标/触屏点击。
- 「分组方式 → 单列表」时没有工作区分组，九宫格不生效（开关状态仍保留）。
